# abogado809-ecosystem-core

Primera aplicación reconstruida del ecosistema para convertir capacidades históricas de Abogado809 en una base modular, verificable y reutilizable.

Las versiones existentes de abogado809 permanecen intactas.

## Stack
Next.js 14, TypeScript, App Router, Tailwind, Prisma/PostgreSQL, NextAuth, Credentials, Google OAuth preparado, bcrypt, Zod, Resend preparado, Cloudinary preparado y Vercel.

## Verification
npm install
npm run build
npm run start
npm run smoke

## Capability lifecycle
RECUPERADO → RECONSTRUIDO → PROBADO → VALIDADO → REUTILIZABLE

La existencia histórica de código no constituye evidencia de capacidad operativa.
